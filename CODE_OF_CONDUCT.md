# Code of conduct

## Our standard

This project adopts the **Contributor Covenant, version 2.1**, in full. The
authoritative text is at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

It is adopted here by reference rather than copied, so that this file cannot
drift out of sync with the canonical version. Please read it — it is short.

In summary: participate in a way that makes other people want to keep
participating. Harassment, personal attacks, demeaning comments, and publishing
others' private information are not acceptable here, in any venue connected to
the project.

## Scope

This applies in every project space — issues, pull requests, discussions, code
review, and commit messages — and whenever someone is representing the project
in public.

## A note specific to this project

CodeAtlas analyses other people's codebases. Issues and pull requests often
include real code, real architecture, and real mistakes, and contributors share
them to get a bug fixed.

Two expectations follow:

- **Be careful with what you post.** Before pasting a snippet or a diagram from
  a work repository, make sure you are allowed to. Reduce it to a minimal
  reproduction where you can.
- **Be decent about other people's code.** A repository someone shared to
  reproduce a parser bug is not an invitation to critique their architecture.
  Fix the bug.

## Reporting

Report conduct issues to `vamsi.iiita@gmail.com`.

Reports are read by the project maintainer. You will get an acknowledgement
within 72 hours and an outcome as soon as the situation is understood. Reports
are kept confidential: the reporter's identity is not disclosed to the person
reported, or to anyone else, without explicit permission.

If your report concerns the maintainer, say so — and if you would rather not
report to the maintainer at all, that is a legitimate position. You are welcome
to raise it publicly in a discussion, or simply to walk away. Nothing here
obliges you to route a complaint through the person it is about.

## Enforcement

Responses follow the Contributor Covenant's enforcement ladder: correction,
warning, temporary ban, permanent ban — chosen in proportion to the behaviour
and to whether it is repeated.

Being right about a technical point does not exempt anyone from this document.
Neither does being a frequent contributor, or being the maintainer.
